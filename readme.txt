== Description ==

Trade Sphare is a clean, modern and responsive WordPress theme designed for blogs, content websites, personal websites, business websites and digital platforms.

The theme focuses on a simple structure, readable content, responsive layouts and easy customization through standard WordPress features.

It works with the WordPress block editor and provides support for custom logos, featured images, navigation menus, widget areas, wide content alignment, responsive embeds and threaded comments.

The theme is translation-ready and supports both left-to-right (LTR) and right-to-left (RTL) languages.

Trade Sphare is designed to be lightweight, reusable and suitable for a wide range of WordPress websites.

== Installation ==

1. Download the Trade Sphare theme ZIP file.
2. Log in to your WordPress administration area.
3. Go to Appearance > Themes > Add New.
4. Select Upload Theme.
5. Upload the Trade Sphare ZIP file.
6. Install the theme.
7. Activate the theme.

== Recommended Setup ==

After activating the theme:

1. Go to Appearance > Customize and configure the available theme settings.
2. Add your site logo from the Site Identity settings.
3. Create a primary navigation menu under Appearance > Menus.
4. Assign the menu to the Primary Navigation location.
5. Create footer menus if required.
6. Assign footer menus to the available footer locations.
7. Go to Appearance > Widgets and configure the available sidebar widgets.
8. Create posts and pages using the WordPress block editor.
9. Set your preferred homepage configuration under Settings > Reading.

RTL behavior can be enabled automatically by WordPress when an RTL language is selected.
