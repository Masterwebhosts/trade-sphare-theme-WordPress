== Description ==

Trade Sphare is a clean and modern WordPress theme designed for blogs, content websites and digital platforms.

The theme provides a responsive layout, RTL support, custom logo support, featured images, navigation menus, widget areas and compatibility with the WordPress block editor.

Trade Sphare is suitable for publishers, content creators, business blogs and informational websites.

== Features ==

* Responsive design
* RTL language support
* Custom logo support
* Custom navigation menus
* Featured image support
* WordPress block editor support
* Wide alignment support
* Responsive embeds
* HTML5 markup
* Widget-ready sidebar
* Footer navigation menus
* Threaded comments support
* Translation-ready text domain
* Accessible navigation and content structure

== Installation ==

1. Download the Trade Sphare theme ZIP file.
2. Log in to your WordPress administration area.
3. Go to Appearance > Themes > Add New.
4. Select Upload Theme.
5. Upload the Trade Sphare ZIP file.
6. Install and activate the theme.

== Recommended Setup ==

After activating the theme:

1. Go to Appearance > Menus.
2. Create a primary navigation menu.
3. Assign the menu to the Primary Menu location.
4. Create footer menus if required.
5. Go to Appearance > Widgets and configure the available widget areas.
6. Go to Appearance > Customize to configure available theme settings.
