A lightweight WordPress theme for publishers, advertisers, and content-focused websites.

== Description ==

Trade Sphare is a lightweight WordPress theme designed for publishers, advertisers, blogs, and content-focused websites.

The theme provides a clean responsive layout, customizable brand colors, homepage sections, navigation support, and WordPress Customizer options.

== Features ==

* Responsive design.
* Custom logo support.
* Custom navigation menu.
* Customizable brand colors.
* Customizable homepage hero content.
* Optional homepage features, blog, and CTA sections.
* WordPress Customizer integration.
* RTL-friendly layout.
* Translation-ready.
* Lightweight and suitable for content-focused websites.

== Installation ==

1. Download the Trade Sphare theme.
2. In your WordPress dashboard, go to Appearance > Themes.
3. Select Add New.
4. Select Upload Theme.
5. Upload the Trade Sphare ZIP file.
6. Activate the theme.

== Customization ==

Go to Appearance > Customize to configure the available theme options, including:

* Brand colors.
* Homepage hero title.
* Homepage hero description.
* Features section visibility.
* Blog section visibility.
* CTA section visibility.
